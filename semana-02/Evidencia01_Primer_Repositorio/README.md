# cern-preparation-program
Repositorio para la preparación y estudio de temas relacionados con el CERN.


# Evidencia 1: Fundamentos de Git y GitHub

Este proyecto documenta la evidencia práctica sobre el uso de herramientas de control de versiones. Durante su desarrollo, se exploró el ciclo de vida completo de un repositorio, pasando de la creación local a la publicación remota en la nube.

### Proceso de desarrollo
Para cumplir con los objetivos de la actividad, se ejecutó el siguiente flujo de trabajo:
* Inicialización del entorno local y seguimiento de los archivos de trabajo.
* Creación de este archivo `README.md` para documentar el propósito del proyecto.
* Registro progresivo de los cambios mediante diversos *commits*, asegurando un historial claro (por ejemplo, la subida de los primeros ejercicios).
* Revisión del registro de versiones para garantizar la integridad de los datos.
* Conexión y sincronización exitosa de los archivos locales con este repositorio remoto.

Esta experiencia práctica sentó las bases para mantener un control organizado y colaborativo en futuras etapas del programa de preparación.
